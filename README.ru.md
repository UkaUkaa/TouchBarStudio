# TouchBar Studio

[English](README.md) · **Русский** · [Українська](README.uk.md)

**Сделайте Touch Bar на своём MacBook Pro по-настоящему полезной.**

Собственные кнопки, живые виджеты, отдельная раскладка для каждого приложения
и обмен раскладками в виде пресетов — в нативном приложении для macOS без сторонних зависимостей.

## Установка

> [!NOTE]
> Нужен **MacBook Pro с Touch Bar** (2016–2020, Intel или Apple silicon) с
> **macOS 14 Sonoma или новее**. Приложение универсальное.

### 1. Скачайте

Со страницы [последнего релиза](https://github.com/UkaUkaa/TouchBarStudio/releases/latest)
скачайте `TouchBarStudio-<версия>.dmg` (рекомендуется) или `TouchBarStudio-<версия>.zip`.

<details>
<summary>Необязательно: проверьте целостность загрузки</summary>

Положите `SHA256SUMS.txt` в ту же папку и выполните:

```sh
cd ~/Downloads
shasum -a 256 -c SHA256SUMS.txt --ignore-missing
```

Напротив каждого скачанного файла должно быть `OK`.

</details>

### 2. Установите

**Из DMG:** дважды нажмите `TouchBarStudio-<версия>.dmg`, перетащите **TouchBar Studio**
на папку **Applications** в открывшемся окне, затем извлеките образ диска (кнопка ⏏
рядом с ним в Finder).

**Из ZIP:** дважды нажмите `.zip`, чтобы распаковать, и перенесите **TouchBar Studio.app**
в `/Applications`.

### 3. Первый запуск

> [!IMPORTANT]
> Приложение не нотаризовано Apple (у него ad-hoc подпись), поэтому при первом запуске
> macOS сообщит, что не может проверить разработчика. Разрешить запуск нужно один раз.

1. Откройте **TouchBar Studio** из папки «Программы». Когда появится предупреждение,
   нажмите **Готово** (или **OK**).
2. Откройте **Системные настройки › Конфиденциальность и безопасность**, прокрутите до
   раздела **Безопасность** и нажмите **Все равно открыть** рядом с сообщением о TouchBar Studio.
3. Подтвердите кнопкой **Все равно открыть** и паролем или Touch ID.

В macOS 14 можно также нажать на приложение в Finder с Control, выбрать **Открыть** и ещё
раз **Открыть**. Или в Терминале:

```sh
xattr -dr com.apple.quarantine "/Applications/TouchBar Studio.app"
```

После этого приложение открывается как обычно.

### 4. Настройка

| Я хочу… | Что сделать |
|---|---|
| Сразу увидеть свою раскладку | Она уже на Touch Bar, пока TouchBar Studio — активное приложение |
| Видеть раскладку **во всех приложениях** | **Настройки › Подключение к Touch Bar** → **Поверх всех приложений** ([что это значит](#как-приложение-попадает-на-touch-bar)) |
| Оставить приложению его собственную Touch Bar (например Xcode или Final Cut Pro) | **Настройки › Приложения со своей Touch Bar** → **Добавить приложение…** или, пока это приложение впереди, **Всегда своя Touch Bar в «<Приложение>»** в строке меню |
| Запускать приложение при входе | **Настройки › Основные › Открывать при входе в систему** |
| Пользоваться кнопками с сочетаниями клавиш и медиаклавишами | **Настройки › Разрешения** → **Предоставить доступ…**, затем включите TouchBar Studio в Системных настройках. Всё остальное работает и без этого |
| Сменить язык интерфейса | **Настройки › Язык** |

### Обновление

Завершите TouchBar Studio и установите новую версию так же, заменив старое приложение
в папке «Программы». Профили и настройки сохранятся.

> [!TIP]
> Если после обновления перестали работать сочетания клавиш, выключите и снова включите
> TouchBar Studio в **Системных настройках › Конфиденциальность и безопасность ›
> Универсальный доступ**: ad-hoc подпись меняется с каждой сборкой.

### Удаление

Завершите TouchBar Studio (если раскладка была поверх всех приложений, обычная Touch Bar
вернётся), затем удалите приложение и, если не хотите сохранять конфигурацию, его папку
с данными:

```sh
rm -rf "/Applications/TouchBar Studio.app"
rm -rf ~/Library/Application\ Support/TouchBarStudio
```

Если вы давали доступ, удалите TouchBar Studio и из **Системных настроек ›
Конфиденциальность и безопасность › Универсальный доступ**.

## Как приложение попадает на Touch Bar

macOS даёт обычному приложению управлять Touch Bar **только пока оно активно**.
Публичного API для изменения Touch Bar других приложений нет. Поэтому в TouchBar Studio
два взаимозаменяемых способа подключения за протоколом `TouchBarProvider`:

| Режим | API | Когда видна ваша раскладка | Профили приложений |
|---|---|---|---|
| **Стандартный** (по умолчанию) | Публичный `NSTouchBar`, привязанный к `NSApplication` | Пока TouchBar Studio — активное приложение | Определяются, но не применяются (в других приложениях панель не показывается) |
| **Поверх всех приложений (эксперимент)**, включается вручную | Недокументированный `+[NSTouchBar presentSystemModalTouchBar:placement:systemTrayItemIdentifier:]` — тот же, что в Pock и MTMR | Поверх любого приложения | Переключаются сами при смене активного приложения |

Экспериментальный режим по умолчанию выключен и перед включением просит подтверждения.
Метод ищется во время работы через `class_getClassMethod`: если в будущей версии macOS
его уберут, опция просто отключится, а не приведёт к падению. Пока включено «Оставлять
системную Control Strip» (по умолчанию), macOS добавляет кнопку закрытия (✕) и оставляет
яркость и громкость.

**Закрытие раскладки в одном приложении (✕).** В экспериментальном режиме системная
кнопка ✕ скрывает раскладку в приложении, которое сейчас впереди, и показывается его
собственная Touch Bar. Это действует только до перехода в другое приложение: там
раскладка показывается, а при возврате в первое приложение она тоже возвращается
(ничего не запоминается). Пока вы ещё в этом приложении, вернуть раскладку можно пунктом
меню «Показать раскладку в «<Приложение>»». Закрытие определяется через KVO на
`NSTouchBar.visible`; на тестовом Mac удержание fn его не меняло, а события во время сна
дисплея, блокировки экрана или на экране входа игнорируются.

## Возможности

### Кнопки и действия

- **Свои кнопки**: заголовок (показан или скрыт), SF Symbol / иконка приложения / файл
  изображения, цвет, действие, необязательная глобальная горячая клавиша (Carbon
  `RegisterEventHotKey`, разрешения не нужны), необязательное связанное приложение.
  Добавление, редактирование, дублирование, удаление и перестановка.
- **Действия** (`ActionRegistry` + `ActionExecutor`, у всех настоящие обработчики):

  | Действие | Примечания |
  |---|---|
  | Открыть приложение · ссылку · файл/папку | — |
  | Сочетание клавиш | Можно отправить конкретному приложению — оно сначала выводится вперёд. Нужен Универсальный доступ |
  | Скопировать текст | — |
  | AppleScript | Нужно одобрение; macOS один раз спрашивает разрешение на Автоматизацию для каждого приложения |
  | Shell-команда | Выключено, пока не включите в Настройках; нужно одобрение |
  | Команда приложения | Встроенные команды для Finder, Safari, Terminal, Xcode, Music и системы |
  | Медиаклавиши | Нужен Универсальный доступ |
  | Микрофон | Переключить / выключить / включить для всех приложений |
  | Последовательность | Выполняет шаги по порядку, останавливается на первой ошибке |

  Ошибки записываются в журнал действий, а кнопка на Touch Bar мигает красным.

### Виджеты

- **Батарея**: живой значок батареи и процент заряда (IOKit power-source API, разрешения
  не нужны). Обновляется при каждом изменении питания, становится оранжевой на 20% и
  красной на 10% при работе от батареи; нажатие открывает настройки аккумулятора
  (можно изменить или отключить).
- **Микрофон**: выключает и включает микрофон для всех приложений через свойство mute
  Core Audio у устройства ввода по умолчанию (разрешения не нужны; у устройств без
  такого свойства громкость входа ставится на 0 и обратно). Пока микрофон выключен,
  виджет красный; он следит за изменениями, сделанными в других местах, и за сменой
  устройства ввода.
- **Часы**: время, время с секундами, дата и время или дата — на языке интерфейса и с
  учётом 12/24-часового формата macOS — или свой формат: день/месяц, месяц/день или
  сначала год, год как ГГ/ГГГГ или без него, разделители даты и времени, секунды, 24/12
  часов, день недели, время до или после даты (например `26.10.26 14:05:09`,
  `10/26 2:05 PM`, `2026-10-26 14:05`) или собственный шаблон даты Unicode. Размер
  текста настраивается (10–24 пт). Нажатие открывает Календарь (можно изменить или
  отключить).
- **Ползунки громкости и яркости**: громкость устройства вывода по умолчанию (Core Audio,
  разрешения не нужны) и яркость встроенного дисплея (приватный фреймворк
  DisplayServices, ищется во время работы). Оба следят за изменениями с клавиш, из Пункта
  управления или от автояркости.
- **Системные кнопки**: яркость и подсветка клавиатуры −/+, громкость −/+, без звука,
  предыдущий / пуск-пауза / следующий трек и системные команды (блокировка экрана,
  снимок экрана, Spotlight, Mission Control…). Кнопки яркости дисплея меняют её
  напрямую и работают без Универсального доступа; остальные отправляются как аппаратные
  клавиши и требуют его.

### Раскладка и внешний вид

- **Редактор раскладки**: превью с подписью «ПРЕВЬЮ — это не настоящая Touch Bar», оценкой
  ширины и предупреждением о переполнении, библиотека компонентов, панель свойств,
  перетаскивание (из библиотеки на панель, перестановка на панели и в списке),
  отмена/повтор (⌘Z / ⇧⌘Z), откат, сохранение и «Сохранить как пресет».
- **Размер иконок**: значение по умолчанию в Настройки › Внешний вид (10–22 pt, обычно 16)
  и свой размер для любой кнопки или виджета.
- **Ширина кнопок**: каждая кнопка и виджет подстраивается под содержимое или получает
  одинаковую фиксированную ширину (30–300 pt); любому элементу можно задать свою
  ширину, а ползункам громкости и яркости — свою длину (60–400 pt). Высота задана
  оборудованием.

### Профили и пресеты

- **Профили приложений**: создание, переименование, дублирование, удаление, профиль по
  умолчанию, привязка приложений, автоматическое переключение. Активное приложение
  определяется через `NSWorkspace.didActivateApplicationNotification`.
- **Пресеты**: Разработчик, Браузер, Автор, Продуктивность, Творчество и Finder.
  Свои пресеты импортируются и экспортируются в версионированный JSON.
- **Приложения со своей Touch Bar**: список приложений, в которых ваша раскладка не
  показывается и остаются их родные кнопки на Touch Bar. Как только впереди другое
  приложение, раскладка возвращается. Список — в Настройках, а приложение, которое сейчас
  впереди, можно добавить или убрать из строки меню. Работает в режиме «Поверх всех
  приложений»; в стандартном режиме у каждого приложения и так своя Touch Bar.

## Язык интерфейса

Английский, русский и украинский — переключаются в **Настройки › Язык** (Системный /
English / Русский / Українська) без перезапуска. «Системный» следует первому
предпочитаемому языку macOS. Стандартные меню и панели macOS (Правка, Окно, диалоги
открытия и сохранения) следуют `AppleLanguages` и меняют язык после перезапуска; в
Настройках для этого есть кнопка **Перезапустить**.

## Безопасность и разрешения

| Разрешение | Для чего | Когда запрашивается |
|---|---|---|
| **Универсальный доступ** | Только сочетания клавиш и медиаклавиши | Никогда при запуске: Настройки объясняют зачем, затем вы нажимаете **Предоставить доступ…** |
| **Автоматизация** | AppleScript, управляющий другим приложением | Спрашивает macOS, один раз для каждого приложения |
| *(не нужно)* | Всё остальное: приложения, ссылки, файлы, текст, виджеты, горячие клавиши | — |

- **Shell-команды** выключены, пока их не включить в Настройках (с предупреждением).
  Они выполняются через `/bin/zsh -lc` с таймаутом (по умолчанию 30 с).
- **Одобрение скриптов**: каждый AppleScript и каждую shell-команду нужно одобрить перед
  первым запуском. Одобрение привязано к SHA-256 точного текста и хранится в
  `approved-scripts.json`, который никогда не экспортируется. Изменение скрипта отменяет
  одобрение. Импортированные пресеты никогда не несут одобрений, а окно импорта
  показывает каждый скрипт целиком.
- **Проверка импорта**: ограничение 512 КБ; проверяются `format` и `formatVersion`;
  структура декодируется строго; ограничены число элементов, длина заголовков и
  скриптов, глубина и число шагов последовательностей; ссылки `javascript:` и
  неизвестные команды приложений отклоняются. Импортированные элементы получают новые ID.
- Файл конфигурации, который не удалось прочитать, переименовывается
  (`config.unreadable-<дата>.json`), а не перезаписывается.

Конфигурация хранится в `~/Library/Application Support/TouchBarStudio/`.

## Ограничения

- **В стандартном режиме раскладка не видна в других приложениях.** Это ограничение macOS,
  его нельзя обойти публичным API — используйте экспериментальный режим.
- **Экспериментальный режим опирается на недокументированный API** и может сломаться с
  любым обновлением macOS.
- Если TouchBar Studio завершилась в экспериментальном режиме и через несколько секунд
  была открыта в стандартном, на тестовом Mac macOS показывала пустую Touch Bar весь этот
  сеанс (воспроизведено 2 из 2; следующий запуск в порядке). Переключение режимов внутри
  работающего приложения не затронуто.
- В стандартном режиме кнопка с сочетанием клавиш без целевого приложения отправляет
  клавиши самой TouchBar Studio (редактор об этом предупреждает).
- Ширина элементов в превью — оценка по снимкам 13-дюймовой Touch Bar (кнопка только с
  иконкой 72 pt, кнопка закрытия 60 pt, свёрнутая Control Strip 306 pt); элементы, которые
  не помещаются, macOS скрывает. Юнит-тест проверяет, что все встроенные пресеты
  помещаются в самую тесную раскладку на всех трёх языках.
- Медиаклавиши яркости и подсветки клавиатуры не предлагаются: на Mac с Apple silicon их
  нельзя надёжно отправить.
- Команды для неустановленных приложений (например Xcode) сообщают «Не установлено
  приложение…», а не делают вид, что сработали.

## Для разработчиков

Swift 6 · AppKit (`NSTouchBar`) для Touch Bar · SwiftUI для интерфейса · без сторонних
зависимостей. Подробности об архитектуре, сборке релизов и проверке на оборудовании — в
[английском README](README.md#for-developers).

### Требования

- macOS 14 Sonoma или новее (разработано и проверено на macOS 27.0.1).
- MacBook Pro с Touch Bar, чтобы увидеть результат. На других Mac приложение работает,
  но управлять ему нечем.
- Swift 6: хватит Xcode Command Line Tools, полный Xcode не обязателен.

### Сборка и тесты

```sh
scripts/build-app.sh            # релизная сборка → build/TouchBar Studio.app
scripts/build-app.sh debug      # отладочная сборка
scripts/test.sh                 # юнит-тесты (Swift Testing)
scripts/release.sh [версия]     # универсальная сборка, DMG, ZIP и SHA256SUMS.txt в dist/
open "build/TouchBar Studio.app"
```

Переводы — это словари Swift в `Sources/TouchBarStudioCore/Localization/`
(`RussianStrings.swift`, `UkrainianStrings.swift`) с английским текстом в качестве ключа.
`LocalizationTests` падает, если перевода не хватает, он не используется или у него не
совпадают плейсхолдеры.
